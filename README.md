# Disease Prediction System

Disease Prediction System using Machine Learning that analyzes patient symptoms and predicts likely diseases using SVM, Gaussian Naive Bayes, and Random Forest. Includes data preprocessing, visualization, model evaluation, and ensemble learning.

## Features
- Patient symptom analysis
- Multiple ML algorithms (SVM, Gaussian Naive Bayes, Random Forest)
- Data preprocessing and visualization
- Model evaluation and comparison
- Ensemble learning approaches
